# JARVIS — คู่มือการใช้งานอย่างละเอียด (Usage Guide)

คู่มือนี้เน้นที่ **การใช้งานประจำวัน** หลังจากที่คุณได้ติดตั้งและเริ่มใช้งานแอปพลิเคชันเรียบร้อยแล้ว

---

## 🚀 การเริ่มต้นใช้งาน JARVIS

```bash
jarvis
```

หากตั้งค่า `GEMINI_API_KEY` ถูกต้อง JARVIS จะ:
- เปิดหน้าต่างอินเทอร์เฟซ UI ขึ้นมา
- เริ่มใช้งานระบบไมโครโฟน
- เชื่อมต่อกับ Gemini Live แบบ Real-time
- รับฟังและตอบกลับด้วยเสียงพูด

---

## 🗣️ ตัวอย่างคำสั่งเสียงที่สามารถพูดสั่งงานได้

### 1) คำสั่งพื้นฐาน (Basic Actions)
- *"เปิด Chrome"*
- *"สภาพอากาศที่กรุงเทพฯ เป็นยังไงบ้าง?"*
- *"ค้นหาข้อมูลบนเว็บเรื่อง..."*

### 2) คำถามเกี่ยวกับหน้าจอ / กล้อง (Screen & Camera)
- *"ตอนนี้หน้าจอฉันมีอะไรอยู่?"*
- *"มองกล้องของฉันแล้วบอกหน่อยว่าเห็นอะไร"*
- *"วิเคราะห์ภาพบนหน้าจอนี้ให้หน่อย"*

### 3) การตั้งเวลาและเตือนความจำ (Reminders & Schedule)
- *"ตั้งเตือนพรุ่งนี้เวลา 8:30 น. ให้โทรหาแม่"*

### 4) การจัดการไฟล์ (File Operations)
เมื่อคุณมีไฟล์ที่อัปโหลดผ่าน UI สามารถสั่งงานได้ดังนี้:
- *"สรุปเนื้อหาไฟล์ PDF นี้ให้หน่อย"*
- *"ดึงข้อความจากภาพนี้"*
- *"ช่วยตรวจและปรับแต่งโค้ดไฟล์นี้ให้ดีขึ้น"*
- *"วิเคราะห์ข้อมูลในไฟล์ CSV นี้"*

### 5) ควบคุมระบบคอมพิวเตอร์ (Desktop Controls)
- *"จัดระเบียบไฟล์บน Desktop แยกตามประเภท"*
- *"ทำความสะอาดโฟลเดอร์ Downloads"*
- *"แคปหน้าจอ (Take a screenshot)"*

### 6) การใช้งานร่วมกับ Gmail (Gmail Integration)
Gmail ใช้ระบบ Google OAuth ในการยืนยันตัวตน:

1. สร้างหรือเลือกโปรเจกต์ใน Google Cloud Console
2. เปิดใช้งาน Gmail API
3. ตั้งค่า OAuth Consent Screen เพิ่มอีเมลของคุณเป็น Test User
4. เพิ่ม Scope `gmail.readonly` และ `gmail.send`
5. สร้าง OAuth Client ID ชนิด **Desktop app** แล้วดาวน์โหลดไฟล์ JSON
6. ลากไฟล์ JSON มาวางใน JARVIS แล้วพูดว่า *"เชื่อมต่อ Gmail ด้วยไฟล์นี้"*
7. ทำการยืนยันสิทธิ์บนหน้าต่างเบราว์เซอร์ที่เปิดขึ้นมา

**ตัวอย่างคำสั่ง Gmail:**
- *"ตรวจสอบการเชื่อมต่อ Gmail"*
- *"แสดงอีเมลที่ยังไม่ได้อ่าน"*
- *"ค้นหาอีเมลจาก `from:alex@example.com`"*
- *"เตรียมร่างอีเมลถึง alex@example.com หัวข้อ รายงานความก้าวหน้า"*
- *"ยืนยันการส่งอีเมล"* / *"ยกเลิกการส่งอีเมล"*

### 7) ระบบวิจัยข้อมูลเชิงลึก (Deep Research)
JARVIS สามารถค้นหาข้อมูลเชิงลึกเปรียบเทียบจากหลายแหล่ง รวบรวมหลักฐาน และบันทึกรายงานสรุปอ้างอิงได้:

- *"ทำวิจัยเชิงลึกเรื่องความคุ้มค่าของการติดตั้งโซลาร์เซลล์ที่บ้าน"*
- *"ค้นหาข้อมูล AI Framework ในท้องถิ่น เน้นเรื่อง Privacy และ Performance บน Mac"*
- *"ทำวิจัยเชิงลึกแบบเร่งด่วนเกี่ยวกับบริษัทนี้ก่อนการสัมภาษณ์"*
- *"ตรวจสอบสถานะการวิจัยข้อมูล"*

ก่อนการวิจัยจะเริ่มขึ้น JARVIS จะถามว่าต้องการให้ทำแบบ **เบื้องหลัง (Background)** หรือ **เปิดเบราว์เซอร์ให้เห็น (Visible)** 
ความลึกในการวิจัยเลือกได้ 3 ระดับ: `quick`, `standard` (เริ่มต้น), และ `deep`

### 8) สร้างสไลด์งานนำเสนอ PowerPoint (.pptx)
JARVIS สามารถสร้าง, แก้ไข, ปรับดีไซน์ และขยายสไลด์ PowerPoint จอกว้าง (16:9) ได้จากเอกสาร ข้อมูล หรือวิดีโอ:

- *"สร้างสไลด์ PowerPoint 8 หน้า เกี่ยวกับพลังงานหมุนเวียนสำหรับนักเรียน"*
- *"สร้างงานนำเสนอระดับผู้บริหารจากไฟล์ PDF และ Excel เหล่านี้"*
- *"ปรับดีไซน์สไลด์ที่อัปโหลด รักษา CI แบรนด์เดิมไว้ แล้วเพิ่ม Speaker Notes"*
- *"ขยายสไลด์นักลงทุนนี้ให้เป็น 20 หน้า แล้วส่งออกทั้งไฟล์ .pptx และ PDF"*

ธีมที่มีให้เลือก: `arc_reactor`, `executive`, และ `platinum` โดยสไลด์จะถูกบันทึกไว้ในโฟลเดอร์ `Desktop/JARVIS Presentations`

## 🔧 การแก้ไขปัญหาที่อาจพบ (Troubleshooting)

### ปัญหา API Key
หากพบข้อความ: `GEMINI_API_KEY environment variable not set`
- **วิธีแก้**: ตรวจสอบว่าไฟล์ `.env` มีอยู่ และได้กรอก `GEMINI_API_KEY` ถูกต้องแล้ว หรือบันทึกผ่านการ์ด Gemini API Key บนหน้าจอ UI

### ปัญหาเสียงพูดไม่ทำงาน
หาก JARVIS ไม่สามารถใช้เสียงที่คุณเลือกได้ ระบบจะสลับไปใช้เสียงเริ่มต้น (`puck`) โดยอัตโนมัติ

### เครื่องมือทำงานล้มเหลว (Tool Failures)
- ตรวจสอบสิทธิ์ของระบบ (ไมโครโฟน, หน้าจอ, เบราว์เซอร์)
- ตรวจสอบว่าติดตั้ง Dependencies ครบถ้วน (เช่น Playwright)
