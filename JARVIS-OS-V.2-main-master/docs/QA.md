# JARVIS — คู่มือการตรวจสอบบั๊กและประกันคุณภาพระบบ (Quality Assurance)

ระบบ QA ของ JARVIS แบ่งออกเป็น 2 ระยะหลัก โดยจะทำการทดสอบอัตโนมัติก่อนเสมอ จากนั้นจึงทดสอบระบบเชื่อมต่อและสิทธิ์การใช้งานของอุปกรณ์จริง ภายใต้กฎความปลอดภัย QA Safety Rules

---

## 🤖 1. การตรวจสอบอัตโนมัติ (Automated Audit)

```bash
python3 scripts/qa.py automated
```

คำสั่งนี้จะเปิดใช้งาน `JARVIS_QA_MODE`, สร้างพื้นที่ทดสอบแบบแยกส่วน (Isolated Workspace), ตรวจสอบการคอมไพล์โค้ด, เช็กไลบรารี Dependencies, รันชุด Test Suite ทั้งหมด, ตรวจสอบรูปแบบคีย์หลุด และออกรายงานในรูปแบบ Markdown และ JSON ไว้ในโฟลเดอร์ `.qa-artifacts/`

---

## 🖥️ 2. การตรวจสอบบนเครื่องจริง (Supervised Audit)

รันรายการตรวจสอบอัตโนมัติที่ปลอดภัย:

```bash
python3 scripts/qa.py checklist-auto
```

คำสั่งนี้จะไม่ขัดจังหวะการทำงาน โดยจะทดสอบการเปิดตัวเครื่อง, การกู้คืนคีย์จำลอง, สายสัญญาณเสียง, เวลาซับไตเติล, การวัดขนาด UI, สวิตช์ธีม, การคุมเบราว์เซอร์ Localhost, สิทธิ์หน้าจอ และสัญญาการทำงานของเครื่องมือ โดยรายการที่ต้องใช้หูฟังมนุษย์หรือการตรวจอุปกรณ์จริงจะถูกทำเครื่องหมายว่า `partial`, `blocked`, หรือ `manual-required` เพื่อความแม่นยำ

หากต้องการทดสอบความเสถียรต่อเนื่องแบบยาวขึ้น:

```bash
python3 scripts/qa.py checklist-auto --stability-seconds 300
```

เริ่มรายการทดสอบสดบนเครื่อง:

```bash
python3 scripts/qa.py live
```

## 🔒 การเปิดใช้สิทธิ์ทดสอบเพิ่มเติม (Optional Capabilities)

คุณสามารถเปิดสิทธิ์ทดสอบการทำงานเฉพาะอย่างได้โดยการตั้งค่า Environment Variables:

```bash
JARVIS_QA_ALLOW_BROWSER=1
JARVIS_QA_ALLOW_DESKTOP=1
JARVIS_QA_ALLOW_DRAFTS=1
JARVIS_QA_ALLOW_REMINDERS=1
JARVIS_QA_ALLOW_MEMORY=1
```

> **หมายเหตุความปลอดภัย**: การส่งข้อความจริง, การสั่งปิด/รีสตาร์ตเครื่องคอมพิวเตอร์ และการเขียนไฟล์นอกพื้นที่ทดสอบ จะถูกบล็อกไว้อยู่เสมอเพื่อความปลอดภัยของผู้ใช้

---

## 📊 รายงานและการจัดการบั๊ก (Reports & Bug Handling)

```bash
python3 scripts/qa.py report
```

รายงานทุกฉบับจะระบุระดับความรุนแรง (Severity), ระบบย่อย (Subsystem), ผลกระทบ และหลักฐานการทดสอบ โดยจัดลำดับความสำคัญดังนี้:
- **P0**: บล็อกการทำงาน (ต้องแก้ทันที)
- **P1**: สำคัญต่อการปล่อยเวอร์ชันใหม่
- **P2**: บั๊กที่วางแผนแก้ไขตามรอบ
- **P3**: การปรับแต่งความสวยงามเล็กน้อย
