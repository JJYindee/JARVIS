# แนวทางการร่วมพัฒนาโปรเจกต์ (Contribution Notes)

ขอบคุณที่สนใจร่วมพัฒนาโปรเจกต์ JARVIS! 🙏

## 📌 ข้อปฏิบัติในการร่วมพัฒนา

1. **Fork & Pull Request**: Fork โครงสร้างโปรเจกต์ไปยังบัญชีของคุณ และส่ง Pull Request เมื่อพัฒนาเสร็จสิ้น
2. **กระชับและเน้นประเด็น**: พยายามให้การแก้ไขในแต่ละ PR มุ่งเน้นไปที่ฟีเจอร์เดียวหรือการแก้บั๊กจุดเดียวเท่านั้น
3. **การทดสอบโค้ด**: รันการทดสอบ (Tests) และตรวจสอบความถูกต้องของโค้ด (Linters) ก่อนส่ง PR เสมอ
4. **อัปเดตเอกสาร**: อัปเดตไฟล์ `README.md` หรือเอกสารในโฟลเดอร์ `docs/` สำหรับการเปลี่ยนแปลงใดๆ ที่มีผลต่อผู้ใช้งาน

---

> ⚠️ **ข้อควรระวังเรื่องความปลอดภัย**: หากคุณพบการหลุดของคีย์ความลับหรือรหัสผ่านโดยไม่ได้ตั้งใจ โปรดแจ้งผู้ดูแลโปรเจกต์ทันที และห้ามแชร์คีย์ความลับนั้นในพื้นที่สาธารณะเด็ดขาด
